# Roth Hydraulics product image sources

Product imagery in this directory is stored locally for the Dutch Roth Hydraulics distributor website operated by Hobo Hydrauliek B.V.

Primary sources are official Roth Hydraulics product pages and official `roth-hydraulics.de` image assets. The workflow `.github/workflows/localize-roth-product-images.yml` preserves the exact fixed URLs and the product-page discovery URLs used for local copies.

The `discovered/` files are automatically extracted from the live official Roth product pages. When Roth does not publish an individual photograph for a named option or special variant, the catalogue deliberately uses an official locally stored family photograph and labels it as representative.
